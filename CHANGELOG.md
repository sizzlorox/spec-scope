## 0.1.0

Initial release.

### Features

* Detect OpenSpec and Spec Kit projects and parse their spec trees into a single model.
* Generate Mermaid diagrams from specs: requirement maps, sequence charts derived from
  `WHEN`/`THEN` scenario steps, task flows from checklists, and per-group overviews.
* Local review server on `127.0.0.1` rendering the spec tree with its diagrams inline.
* Anchored discussion notes on any document, requirement, scenario or group, stored in
  `.spec-scope/notes.json`.
* Agent review loop: `spec-scope poll` long-polls for open notes, `spec-scope resolve` closes them.
* `spec-scope export` writes a self-contained single-file HTML tech doc with Mermaid and Marked
  inlined — no network access required to open it.
